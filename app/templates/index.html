Генератор КТП

Проставляет даты занятий в плане .doc по календарю часов .xlsx (праздники пропускаются)

1. План КТП (.doc)

Перетащите сюда файл .doc
или нажмите, чтобы выбрать

2. Календарь часов (.xlsx)

Перетащите сюда файл .xlsx
или нажмите, чтобы выбрать

3. Расписание

{%- for wd in weekdays %} {{ wd }} {%- endfor %}
Праздничные (красные) дни календаря автоматически пропускаются. Исходный документ не изменяется — создаётся новый файл в папке output/.
